# DAC_Modification_History

## 概要

本リポジトリでは、DACおよびオーディオ機器の改造履歴を記録・公開しています。

主な内容は以下の通りです。

- 改造内容
- 使用部品
- FFT測定結果
- FFT測定画像
- 試聴結果
- 採用構成
- 技術的考察

改造による変化を可能な限り測定結果と試聴結果の両面から記録し、後から追跡・比較できる形で保存することを目的としています。

## 公開方針

本リポジトリでは以下を重視しています。

- 事実と考察を分離する
- FFT測定結果を可能な限り公開する
- 試聴結果を併記する
- 採用理由を記録する
- 失敗事例や試行錯誤も記録する

測定結果と試聴結果に差がある場合は、その両方を記録し、無理に結論付けない方針としています。

## 測定環境

測定は主に以下の環境で実施しています。

- SB-1240改
- WaveGene
- WaveSpectra
- Windows 11
- 24bit / 96kHz

測定条件は各レポート内に記載しています。

## 記録方法

各改造について、

変更内容
↓
FFT測定
↓
試聴
↓
考察
↓
採用可否

の流れで整理しています。

## 目的

本リポジトリは、

「改造した」
だけではなく、
「なぜその構成を採用したのか」

を記録することを目的としています。

将来的な再検証や、次世代機器との比較資料として活用するため、可能な限り測定データと試聴結果を残しています。

## 注意事項

- 本リポジトリに掲載している改造内容は個人による検証結果です。
- 改造は自己責任で実施してください。機器の破損や事故等について責任を負いません。
- 測定結果や試聴結果は測定環境・試聴環境に依存します。同一結果を保証するものではありません。
