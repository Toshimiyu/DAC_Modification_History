【SMSL D1 改 Ver4 → Ver5（正式版）まとめと総評 / TEXT】
■ 1. 改修の目的
ギターの高速ピッキング奏法で発生していた
「アタックが曖昧になる・粒が団子になる・高域に靄が乗る」  
という現象を改善するため、
DAC の 時間軸の揺れ・高域歪みの質・電源応答 を総合的に整えることを目的とした。

■ 2. 改修履歴の要点（Ver4 → Ver5）
● Ver4
DAC AVCC に X7R 1µF

デジタルLDO入力に 22µF ハイブリッド
→ 電源の揺れを止め、ノイズフロアを整える段階

● Ver5（正式版）
±レール LDO 入力：FG 10µF + X7R 3.3µF

±レール LDO 出力：PLMCAP 4.7µF

デジタルLDO出力：C0G 0.01µF
→ アナログ電源の質を整え、デジタル電源の時間軸を仕上げる段階

■ 3. 無音スペクトル（300回平均）
● Ver4
7.5kHz〜40kHz が -130dB帯でフラット

1kHz近傍 -112dB
→ 非常に静かで均一な床

● Ver5
7.5kHz〜40kHz が -127〜-129dB帯でフラット

1kHz近傍 -110dB
→ 床の揃い方は Ver4 と同等。
　高周波インピーダンスがより自然な形に整う。

■ 4. 歪み特性（100Hz / 1kHz / 10kHz / 20kHz）
● 100Hz
Ver4：0.00043%

Ver5：0.00050%
→ 差はほぼゼロ。低域は変化なし。

● 1kHz
Ver4：0.00144%

Ver5：0.00113%
→ 中域の高調波の落ち方がより素直になり、歪みの“質”が改善。

● 10kHz
Ver4：-88 → -100 → -121 dB

Ver5：-88 → -103 → -117 dB
→ 3次が深く沈み、4次が少し上がる“高速応答型”の形へ。
　高域の抜けが良くなる方向。

● 20kHz
Ver4：40kHz = -83.95 dB

Ver5：40kHz = -84.34 dB
→ DAC＋アナログ段の限界は同等。

■ 5. IMD（19kHz + 20kHz）
● Ver4
1kHz IMD：-115.9 dB

サイドバンド：-113 / -112 dB
→ 電源の揺れは止まっているが、時間軸の微細な揺れが残る。

● Ver5
1kHz IMD：-111.3 dB

サイドバンド：-115.2 / -114.6 dB
→ 左右対称性が改善し、時間軸の揺れが最小化。
　“速い音の粒立ち”に直結する改善。

■ 6. 技術的総評（Ver4 → Ver5）
● Ver4
電源の揺れを止めた“静けさの完成形”

ノイズフロアが美しく揃い、中域の歪みの質が整う

● Ver5
±レールの応答速度とインピーダンスが整う

デジタルLDO出力のリンギングが消え、時間軸が安定

高域の高調波列が“速い方向”に整列

IMD の左右対称性が改善し、高速トランジェントの再現性が向上

■ 7. 聴感で予想される改善点（ギターの高速ピッキング）
アタックの頭が“ボワッ”から“カチッ”へ

速いピッキングでも粒が団子にならず、整列して聞こえる

ピッキングノイズが“耳障り”ではなく“情報”として出る

高域の抜けが良くなり、靄が減る

音像の揺れが減り、定位が安定

空間の奥行きが深くなる

【最終総評】
Ver4 は「静けさの完成形」。  
Ver5 は「その静けさの中で、時間軸まで整えた最終仕上げ」。

ギターの高速ピッキングで感じていた“靄”の原因である

時間軸の揺れ

高域歪みの質

電源応答の遅れ
これらが Ver5 で総合的に改善され、
高速トランジェントの再現性が最も高い状態に到達した。
