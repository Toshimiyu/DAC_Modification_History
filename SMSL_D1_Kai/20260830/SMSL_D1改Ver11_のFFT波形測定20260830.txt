◆ SMSL D1改 Ver10 → Ver11 FFT差分レポート（2026/08/30）
🎯 総評（最重要ポイント）
1. 無音ノイズフロアは全帯域で改善（特に高域）
20kHz〜45kHz帯で +5〜7 dB ほど静かになった

10kHz帯も +4〜6 dB 改善

1kHz付近は ほぼ横ばい（-114 → -115 dB）

→ 高域の静けさは明確に向上。背景の黒さが増した。

2. THD / THD+N はほぼ横ばい（改善なし）
100Hz：微悪化（0.00044% → 0.00048%）

1kHz：微悪化（0.00071% → 0.00077%）

10kHz：横ばい（0.01152% → 0.01156%）

20kHz：横ばい（0.00581% → 0.00588%）

→ 歪み成分はほぼ変わらず。ノイズフロア改善が主効果。

3. IMD（19+20kHz）はほぼ横ばい
THD+N：0.01603% → 0.01614%（誤差レベル）

→ IMDは改善せず。オペアンプ高域安定度は変化なし。

→ スイッチング高調波の減衰（40〜45kHz）

→ THD/IMDには影響なし
