無音スペクトルの見方
低域〜中域（100Hz〜10kHz）

Ver9とVer10で、スパイク位置・レベルともにほぼ同じ。

一部で +1〜2dB程度の上下はあるが、測定再現性の範囲内。

10〜40kHz帯

20kHz〜40kHzのノイズフロアは、両方とも -130〜-137dBクラス。

足直X7R 1µF追加で「高域ノイズが沈んだ」というほどの変化は出ていない。

→ 電源系・USB系・DAC周りはすでにかなり整っていて、
今回の足直1µF追加は「FFT上ではほぼ見えないレベルの微調整」にとどまっている感じ。

THD/THD+Nの帯域別評価
100Hz
THDが 0.00046% → 0.00044% と、ほんのわずか改善。

2次（200Hz）が -110.81dB → -112.17dB と、2次高調波は少し下がっている。
→ ここは「足直1µFが効いた」というより、測定ばらつき＋電源の安定度の微妙な差くらいの印象。

1kHz
THD 0.00076% → 0.00071%、THD+N 0.00238% → 0.00235%。

2次（2kHz）は -113.94dB → -120.35dB と、ここは明確に下がっている。

3次（3kHz）は -108.04dB → -109.26dB と、わずかに改善。

→ 1kHz帯の偶数次歪みは、Ver10で確かに少し沈んでいる。
　ここは足直1µFで電源インピーダンスがわずかに整った効果が、
　「FFT上でギリギリ見える」レベルで出ているポイント。

10kHz
THD 0.01144% → 0.01152%、THD+N 0.01539% → 0.01542%。

2次（20kHz） -102.54dB → -102.30dB

3次（30kHz） -89.39dB → -89.34dB

→ 高域の歪み構造は、ほぼ完全に同じ。
　足直1µF追加だけでは、
　MUSES7921＋ミラーC 10pF＋BD34352EKVの高域非線形にはほとんど触れていない。

20kHz
THD 0.00581% → 0.00581%（完全一致）。

THD+N 0.00867% → 0.00858% と、わずかに改善。

2次（40kHz） -95.49dB → -95.46dB（ほぼ同じ）。

→ ここも「変化なし」と見てよいレベル。

IMD（19kHz+20kHz）
THD 0.00441% → 0.00440%

THD+N 0.01599% → 0.01603%

1kHz IMD成分：-119.53dB → -119.91dB（わずかに沈む）

18kHz / 21kHzサイドバンド：両方とも -102 / -101dB で完全一致レベル

→ 高域の相互変調構造も、Ver9とVer10でほぼ変化なし。
　足直1µFは「IMDを大きく変えるほどの要素にはなっていない」。

結論：Ver10の足直X7R 1µFは「微細な安定度向上」止まり
FFT上で明確に「効いた」と言えるのは、1kHz帯の2次高調波が少し沈んだことくらい。

高域（10kHz・20kHz・IMD）の歪み構造は、Ver9とほぼ完全に同じ。

無音スペクトルも、電源系・USB系・DAC周りはすでに十分整っていて、今回の変更はほぼ見えないレベルの微調整。

つまり——
Ver10は「悪化ゼロ・わずかな安定度向上・音質的には安心してそのまま使えるが、FFT的にはほぼVer9と同等」という位置づけ。
