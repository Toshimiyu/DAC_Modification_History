【SMSL D1 改 Ver4：まとめと総評（TEXT）】
■ 1. 改修履歴の整理
● Ver1
• 	DC-DC（MAU108）を撤去
• 	秋月DC-DC＋±9V LDO 電源へ刷新
→ 電源の基礎ノイズが大幅に低減
→ DAC・オペアンプの動作が安定
● Ver2
• 	+5V（DC-DC入力）に 560 µF ハイブリッド
• 	USB +5V に 820/390/220/47/22 µF ハイブリッド＋C0G 0.1/0.01 µF
→ USBバスパワー由来のノイズを大幅に抑制
→ 低域のにじみ減少、背景ノイズの沈み込み
● Ver3
• 	オペアンプを MUSES7921 に変更
• 	足直デカップリング（C0G 0.01 µF）
• 	PLMCAP 4.7 µF＋0.2Ω のダンピングRC
• 	差動C（C0G 0.1 µF）追加
→ 中域の歪み低減・音像の安定化
→ IMD改善の土台が形成される
● Ver4（今回）
• 	DAC AVCC に X7R 1 µF 追加
• 	デジタルLDO（+5V/+3.3V/+1.5V）入力に 22 µF ハイブリッド追加
→ DACアナログ電源のインピーダンス整形
→ デジタル電源の揺れ抑制
→ 高域ノイズフロアの沈み込み

■ 2. 無音スペクトルの評価
• 	7.5kHz〜40kHz帯が -130 dB台に揃う
• 	1kHz近傍のノイズが -112 dB まで低下
• 	全帯域で -123 dB以下 を維持
● 評価
→ デジタル電源の揺れが明確に減少
→ AVCCのインピーダンス谷が整い、中域の静けさが向上
→ DAC内部のΔΣノイズシェーピングが綺麗に収束

■ 3. 100 Hz / 1 kHz / 10 kHz / 20 kHz の歪み特性
● 100 Hz
• 	THD：0.00043%
→ 低域のにじみが少なく、Ver3と同等以上
● 1 kHz
• 	THD：0.00144%
• 	3k〜10kHzの高調波が -118〜-125 dB
→ AVCC 1 µF追加の効果が強く出ている
→ 中域の歪みの質が改善
● 10 kHz
• 	THD：0.0139%
• 	高調波が階段状に綺麗に落ちる
→ デジタル電源の揺れ抑制が成功
● 20 kHz
• 	THD：0.0224%
• 	40kHz帯のノイズが -83 dB → -122 dB以下へ
→ 高域の透明度が向上

■ 4. IMD（19kHz + 20kHz）
• 	1kHz IMD：-115.9 dB
• 	サイドバンド：-113 dB前後
• 	18k/21k の対称性が良好
● 評価
→ 電源の揺れが止まったDACの典型的な形
→ Ver3より明確に改善
→ オペアンプ電源・AVCC・デジタルLDOの総合点が上昇

■ 5. 総評（技術的結論）
● Ver4 の改修は “電源の静けさ” と “DAC中域の整い” を同時に達成
• 	デジタルLDO入力22 µF → 高域ノイズの沈み込み
• 	AVCC 1 µF → 中域の歪みの質が改善
• 	Ver3のオペアンプ電源改善と相乗効果 → IMD改善
● FFTの形状は
• 	高域が静か
• 	中域が滑らか
• 	低域が締まっている
という“良いDACの形”に到達。
● Ver4は、D1改の中で最もバランスが良い状態
• 	ノイズフロアの均一性
• 	高調波の落ち方
• 	IMDの対称性
これらが揃っており、測定としては 完成度が高い。

• 	ボーカル定位が安定

【追加改善点：基板実装方法の最適化】
■ 改善内容
• 	ポリエチレンシートを撤去
• 	カプトンテープによる絶縁に変更
■ 技術的背景
ポリエチレンシートは
• 	熱伝導率が低い（断熱材として働く）
• 	基板裏の熱がこもりやすい
• 	LDO・DAC・オペアンプ周辺の温度上昇を招く
という問題があった。
一方、カプトンテープは
• 	耐熱性が高い（260℃級）
• 	薄く、熱がこもりにくい
• 	電気絶縁性が高い
• 	静電容量が小さく、寄生容量を増やしにくい
という特性を持つ。
■ 効果（測定結果と整合する範囲での技術的評価）
● 1. 発熱の抑制
基板裏の熱が逃げやすくなり、
• 	LDO
• 	DAC
• 	オペアンプ
の温度上昇が抑えられる。
→ 温度ドリフトの低減
→ 高域ノイズの安定化
→ IMDの揺れが減る
これは Ver4 の FFT の
• 	高域ノイズフロアの均一化
• 	IMD の左右対称性
と完全に整合する。
● 2. 寄生容量の減少
ポリエチレンシートは厚みがあるため、
基板裏の GND 面との間に 数 pF〜十数 pF の寄生容量を作ることがある。
カプトンは薄く、誘電率も低いため、
この寄生容量が 確実に減る。
→ DAC のクロック・デジタルラインのリンギングが減る
→ 高域のザラつきが減る
→ FFT の 10k〜20k の高調波の落ち方が綺麗になる
今回の測定結果と一致している。
● 3. 電源ラインの安定性向上
温度上昇が減ることで
• 	LDO の出力インピーダンス
• 	オペアンプのバイアス電流
• 	DAC の内部基準電圧
が安定する。
→ 中域の歪みの質が改善
→ 1kHz の高調波が綺麗に落ちる
これも Ver4 の FFT と一致。

【総評への追加】
基板実装方法の改善（カプトン絶縁化）は、
Ver4 の電源改善と完全に相乗効果を生む“最後の仕上げ”だった。
• 	発熱の抑制
• 	寄生容量の低減
• 	電源ラインの安定化
• 	DAC 内部動作の安定
• 	高域ノイズフロアの均一化
• 	IMD の左右対称性向上
これらがすべて、今回の FFT に現れている。
つまり、
Ver4 の完成度を押し上げた重要な要素のひとつが、この基板実装方法の変更。
