◆ SMSL D1 電源改造（Ver1）
FFT測定まとめ & 総評（2026/04/08）
【1. 全体総括】
今回の電源改造は、
「アナログ段の微小歪み」と「高域ノイズの質」を改善する方向に確実に効いた。
特に 1kHz FFT では、
• 	THD が約 −2.6 dB 改善
• 	3次高調波（3kHz）が −6 dB 改善
という、電源改善としては非常に明確な効果が確認できた。
一方で、DAC の構造的限界が支配する
100Hz / 10kHz / 20kHz / IMD では改善は小さく、
電源変更の影響が出る帯域と出ない帯域が明確に分離した点も興味深い。

【2. 無音時スペクトルの変化】
● 改善点
• 	6〜40kHz のノイズフロアが 1〜4 dB 静かに
• 	特に 10.5kHz 付近は 約 2.5 dB 改善
• 	全体的に“揺れ”が減り、ノイズの質が滑らかになった
● 変化が小さい点
• 	1kHz付近のビートノイズは 約1 dB 改善に留まる
→ DC-DC の残留成分がわずかに残る構造

【3. 100Hz FFT（-10 dB）】
• 	THD：わずかに改善（0.00041 → 0.00038%）
• 	THD+N：ほぼ同じ
→ 低周波帯は電源改善の影響が小さい
（DAC内部構造の影響が支配的）

【4. 1kHz FFT（-10 dB）※最大改善帯域】
● THD
0.00145% → 0.00101%
→ 約 −2.6 dB 改善
● THD+N
0.00477% → 0.00452%
→ 約 −0.5 dB 改善
● 高調波の改善量
• 	2kHz：+1.7 dB
• 	3kHz：+6 dB（最大改善）
• 	5〜10kHz：+2〜5 dB
● 評価
電源レールの揺れが減り、アナログ段の動作点が安定した結果、
微小非線形が大幅に抑制された。
今回の改造の“主役”はここ。

【5. 10kHz FFT（-10 dB）】
• 	THD：ほぼ同じ
• 	2次（20kHz）：ほぼ同じ
→ DAC の構造的限界が支配的で、電源改善の影響は限定的

【6. 20kHz FFT（-10 dB）】
• 	THD：ほぼ同じ
• 	2次（40kHz）：完全に同じ
→ 高域は DAC の限界が支配的で、電源改善の影響はほぼ出ない

【7. IMD（19kHz + 20kHz）】
• 	サイドバンド（18kHz / 21kHz）は ±0.1 dB 程度の差
→ IMDもDAC内部構造が支配的で、電源改善の影響は小さい

◆ 最終総評（要点）
● 効果が大きかった帯域
• 	1kHz FFT（最大改善）
• 	3次高調波（−6 dB）
• 	6〜40kHz のノイズフロア（1〜4 dB改善）
● 効果が小さかった帯域
• 	100Hz
• 	10kHz
• 	20kHz
• 	IMD（19+20kHz）
● 改造の本質的効果
• 	電源レールの高周波ノイズが減少
• 	レールインピーダンス低下によりアナログ段が安定
• 	微小歪み（特に3次）が大幅に減少
• 	ノイズフロアの“揺れ”が減り、質が滑らかに
● 総合評価
「電源を変えると、アナログ段の微小歪みと高域ノイズの質が変わる」
という典型的かつ理想的な改善結果。
今回の改造は、
“音の透明度・静けさ・倍音のにじみ”に効くタイプの改善
として非常に筋が通っている。
