REWでの各種測定データから、OPA2140への変更および18 pFの位相補償追加を行った「SB-1240改」は、高域の寄生振動が完全に収まり、帯域全体で極めて高い直線性・低歪み・理想的な位相特性を獲得していることが実証されました。

1. 高調波歪み（THD / THD+N）特性

100 Hz: THD 0.0017% / THD+N 0.010%（ENOB 14.7 bits / SNR 79.9 dB）

1 kHz: THD 0.0045% / THD+N 0.010%（ENOB 14.7 bits / SNR 80.9 dB）

10 kHz: THD 0.015% / THD+N 0.018%（ENOB 13.9 bits / SNR 79.5 dB）

20 kHz: THD 0.028% / THD+N 0.030%（ENOB 13.1 bits / SNR 79.9 dB）

低域〜中域（100 Hz〜1 kHz）においてTHD 0.0017%〜0.0045%という非常に優れた低歪み率を記録しています。20 kHzにかけて歪み率がわずかに上昇していますが、これは高周波域におけるオペアンプの開ループゲイン低下に伴う正常な物理現象であり、0.03%以下に綺麗に抑え込まれています。

2. 混変調歪み（IMD）特性

DIN (250 Hz / 8 kHz): 0.023%

SMPTE (60 Hz / 7 kHz): 0.018%

CCIF (19 kHz / 20 kHz): 0.023%（DFD2: 0.00060% / DFD3: 0.0033%）

複数の周波数が混在する入力環境（IMD測定）でも、歪み成分は0.02%前後と一貫して低く保たれています。CCIFにおける差分混変調（DFD2 = 0.00060%）が極めて小さいため、複雑な楽曲信号を入力した際にも音の濁りや「混濁感」が一切生じない素直な信号処理が行われています。

3. 時間軸・位相特性（GD / Spectrogram / Waterfall）

Group Delay (GD): 20 Hz〜20 kHzの全可聴帯域において、約 -7.99 µs（ほぼ完全な 0 ms）で水平な直線を描いています。帯域ごとの群遅延差や位相ズレが皆無です。

Spectrogram / Waterfall: 信号入力停止後のエネルギー減衰が極めて迅速かつ均一です。特定の周波数で尾を引く寄生振動や余韻の残存（リンギング）は一切見られません。
