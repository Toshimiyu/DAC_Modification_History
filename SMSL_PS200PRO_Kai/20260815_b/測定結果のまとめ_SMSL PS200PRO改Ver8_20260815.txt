🎯 Ver7 → Ver8 差分の核心まとめ（技術的に正確）
改善したポイント（高域ノイズフロア・微細成分）
FFT高域（7.5kHz〜15kHz）で 1〜2dB沈み込みが増加

10.5kHz付近は −147.64dB → −149.53dB と明確に改善

7.5kHz帯は −143.03dB → −145.45dB と改善

8.25kHz帯も −143.26dB → −145.16dB

→ USB入力部のKZ 47µF + X7R 1µF追加が高域ノイズに効いている。

ほぼ変わらないポイント（中域THD）
1kHz THD：
0.00095% → 0.00100%（誤差範囲）

1kHz THD+N：
0.00252% → 0.00253%（完全に同等）

→ 中域は電源インピーダンスの“量”より“位相補償”の影響が支配的なので、Ver8の変更では動かないのが自然。

改善したポイント（高域THD）
10kHz THD：
0.00963% → 0.00935%（改善）

20kHz THD：
0.00466% → 0.00446%（改善）

→ 高域の電源インピーダンスが改善したことで、
　ミラーC 22pFの位相補償がより安定に働く状態になったと推測できる。

IMD（19+20kHz）はほぼ同等
THD：
0.00575% → 0.00569%

THD+N：
0.01900% → 0.01906%

→ CCIFはオペアンプの高域特性が支配的なので、
　電源の高周波補正だけでは大きく動かないのが自然。

🔧 技術的総括（Ver8の意味）
Ver8は「高域の仕上げ」として成功している。
USB入力部のKZ 47µFは
→ 微細成分の改善
→ 高域ノイズの沈み込み
→ 空間表現の改善
に効くタイプの電解。

X7R 1µF追加は
→ 高周波補正の最終仕上げ
→ DC-DC入力のリップル低減
→ LDO出力の過渡応答改善
に効く。

その結果として：

✔ FFT高域が広帯域で改善
✔ 10kHz・20kHz THDが改善
✔ 低域THDもわずかに改善
✔ 中域は変わらず（自然）
